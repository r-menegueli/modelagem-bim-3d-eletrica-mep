# Premissas do estudo — Subestação GIS

Estudo demonstrativo para portfólio. Tensões, carga, fator de potência, potência e impedância dos transformadores são premissas, não dados de rede, fabricante ou campo.

## Modelo Revit

O layout inclui paredes nativas Revit para as edificações esquemáticas e elementos DirectShape categorizados como Electrical Equipment para bays, cubículos, transformadores e painéis; canaletas e barramentos conceituais ficam em Generic Models. Os DirectShapes não são famílias de fabricante, não têm conectores elétricos e não formam circuitos MEP.

## Limites

A geometria não verifica isolamento, afastamentos elétricos, estrutura, acesso, ventilação, incêndio, ruído ou requisitos ambientais. Proteções, aterramento, curto completo e coordenação não foram dimensionados. Não usar para obra, compra, aprovação ou instalação.
